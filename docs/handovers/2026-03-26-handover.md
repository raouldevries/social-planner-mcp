### Critical Bug: LinkedIn Video Finalize Fails

The `uploadVideo()` method in `publisher.service.ts` sends empty `uploadedPartIds: []` to LinkedIn's `finalizeUpload` endpoint. LinkedIn requires the `etag` from each chunk upload response as part IDs. Without these, finalize fails with:

```
"Invalid multipart upload request with no part upload response"
```

The code then polls for processing (which times out after 5 min), creates the post anyway with an unprocessed video URN, and LinkedIn accepts the post but the video never appears.

Additionally, the scheduler's 60-second recurring check keeps picking up the same PENDING channel and creating DUPLICATE publish jobs (each uploading the video again).
