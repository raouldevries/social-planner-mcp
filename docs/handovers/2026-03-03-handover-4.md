## Key Decisions

| #   | Decision                     | Choice                                              | Rationale                                                                                      |
| --- | ---------------------------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1   | Selector generation strategy | `nth-of-type` with `data-feedback-target` preferred | `nth-child` miscounts with mixed-tag siblings; `data-feedback-target` is the stable identifier |
| 2   | Screenshot failure handling  | Log + continue without screenshot                   | Silent failures hide systematic selector bugs; logging ensures observability                   |
| 3   | Submit error handling        | Leave popover open on failure                       | Prevents orphaned screenshot assets from re-upload on retry                                    |
| 4   | html2canvas output format    | JPEG quality 0.7, scale 1                           | Keeps payload small (~100–500KB vs multi-MB PNG); server validates 5MB decoded max             |
