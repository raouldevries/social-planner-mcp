## Key Decisions

| #   | Decision                          | Choice                                                      | Rationale                                                                     |
| --- | --------------------------------- | ----------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 1   | Feedback interaction model        | Annotation-style: click page section                        | User wanted no ambiguity about what feedback refers to                        |
| 2   | Feedback storage                  | Database + email notification to admins                     | Best practice: DB for review/filter, email for immediate awareness            |
| 3   | Feature flag                      | `VITE_FEEDBACK_ENABLED` env var                             | Temporary feature, easy toggle and removal                                    |
| 4   | Screenshot capture                | html2canvas on selected element                             | Captures element context, base64 upload to S3/MinIO                           |
| 5   | LinkedIn token refresh            | Show "Reconnect" (OAuth re-auth) instead of "Refresh Token" | LinkedIn API doesn't support token refresh — requires full re-authentication  |
| 6   | Modal detection for feedback mode | `aria-modal="true"` query                                   | z-50 class is unreliable — dropdowns and other non-modal elements also use it |
