# Session Handover — 2026-03-05

## Session Goal

Investigate why a post published to Instagram with images but LinkedIn only received text (no images), and create an implementation plan to fix it.

## What Was Done

- Pulled 9 new commits from origin/main (feedback replies, ambassador emails, image reordering, carousel preview)
- Researched the full LinkedIn publishing flow: channel service → scheduler → publisher service → LinkedInAdapter
- Identified root cause: `LinkedInAdapter.publish()` destructures only `{ content, accessToken, platformAccountId }` and ignores `mediaUrls` entirely
- Researched LinkedIn's official Image API and Posts API documentation (Microsoft Learn) to understand the required 3-step upload flow
- Created a structured implementation plan at `memory-bank/plans/linkedin-image-publishing-support-plan.md`

## Key Decisions

| #   | Decision              | Choice                                                                                | Rationale                                                                                                   |
| --- | --------------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 1   | Image upload approach | Binary upload via LinkedIn Images API (initializeUpload → PUT binary → post with URN) | LinkedIn doesn't support URL-based image passing like Instagram; binary upload is the only supported method |
| 2   | Single vs multi-image | Use `content.media` for 1 image, `content.multiImage.images` for 2+                   | LinkedIn API uses different content structures for single vs multi-image organic posts                      |
| 3   | Upload strategy       | Sequential image uploads                                                              | Respects LinkedIn rate limits (100 API calls/day on dev tier) and avoids upload URL expiry issues           |
| 4   | Max images            | Cap at 20                                                                             | LinkedIn MultiImage API enforces a 2-20 image limit                                                         |
